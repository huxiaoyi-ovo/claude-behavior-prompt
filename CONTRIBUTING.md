# Contributing

Contributions are welcome.

Good contributions include:
- behavioral rules supported by public evidence;
- cross-model tests showing where the prompt works or fails;
- shorter variants that preserve behavior;
- regression prompts for ambiguity, sycophancy, uncertainty, retrieval, and correction behavior.

Please avoid:
- claiming access to private model internals without evidence;
- copying large proprietary prompt dumps verbatim into this repository;
- adding personality adjectives that do not translate into concrete behavior.

When proposing a behavioral change, explain what failure mode it addresses and provide at least one test prompt.
